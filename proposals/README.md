# proposals/ — drafted-but-inert machinery

Per `docs/FIX-PROTOCOL.md` §10 (**Draft-for-OK**, #7): when a build surfaces a
recurring need for a NEW subagent, a protocol change, or any new machinery,
Claude Code **drafts** it here as a spec file and flags it in the final summary.

A file in this directory is a **suggestion, not a fait accompli**:

- NOT registered — a drafted agent is NOT copied to `.claude/agents/`.
- NOT wired into `docs/FIX-PROTOCOL.md`.
- NOT run.

It stays inert until Preston reviews it and explicitly lands it (moves/wires it
to its real home) in a deliberate commit. **CC never self-activates its own
machinery.**
