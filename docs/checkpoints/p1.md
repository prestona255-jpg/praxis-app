Decisions taken inside the spec (mine, for the gate):
- Commands run through System.Diagnostics.Process with both pipes read asynchronously, so stderr can never
  throw under `$ErrorActionPreference = 'Stop'`, and the exit code is the process's own.
- A timed-out command is ended with `taskkill /T /F` (its whole tree: run.ps1 starts a server and Chrome),
  and reads `exit -1` with the detail "timed out".
- Suite and file lists are sorted ORDINAL, so the order is `_template`, `fb-1a`, `fb-1a-extras` on every
  machine (a culture sort ignores hyphens).
- The empty-list FAIL lines carry the ids `parse none found` and `rig none found`, `exit 1`.
- `prove-red` reads `exit 1  0.0 s`.
- One INFO line beyond the five: `INFO logs %TEMP%\<folder>`, so the log folder is printed as the spec asks.
- Every printed line passes through a scrubber that writes %TEMP% and %USERPROFILE% in place of those
  paths, so a failing harness that names a file it could not load still prints no profile path.
