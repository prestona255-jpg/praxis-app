## The method (Preston's ruling, applied mechanically)

Role is read from the DECLARATION — property + selector + the rule's own fill — then from the literal's colour:

| role | when | proposed token |
|---|---|---|
| fill-page | the room scope's own ground (`.bk-surface.lum-amber-deep`, `.pf-root`, `.u-ground-atmo` …) | `--page` |
| fill-card | a light fill on a card / sheet / panel; the raised part of a sunk control (selected segment, toggle knob) | `--page-2` |
| fill-sunk | a light fill on a chip, pill, tab, seg, spine, track, toggle, field, placeholder, swatch | `--page-3` |
| fill-dark | an opaque dark fill, ranked by today's lightness in its sheet (darkest → sky) | `--sky` / `--umber` / `--umber-2` |
| text-1/2/3 | dark text, ranked by lightness within the sheet (0.1-luminance buckets, so near-equal values share a rank) | `--ink` / `--ink-2` / `--ink-3` |
| text-1 on gold | dark text in a rule whose OWN background is a gold fill (read from the rule, not guessed from the name) | `--on-gold` (§1) |
| text-on-dark-1/2/3 | light text, same ranking | `--on-night` / `-2` / `-3` |
| gold-fill | an opaque gold fill you press | `--gold` |
| gold-text | gold as text, a focus ring, an opaque gold rule | `--gold-ink` |
| gold-on-sky | bright gold that only reads on a dark ground | `--gold-star` |
| border | a hairline / separator · a field's boundary · a light hairline on a dark ground · a border-drawn icon (chevron) → `--ink-3` ? | `--line` · `--line-field` · `--line-night` |
| shadow | the WHOLE box-shadow becomes one token: covers → `--shadow-cover`; sheets, panels, menus, pickers, toasts, docks, bars → `--shadow-float`; everything else → `--card-hi`. Where a declaration mixes `var()` layers (a focus ring) with literal layers, only the literal layers become the token: `box-shadow: var(--x), <kept var() layers>` | as named |
| overlay | translucent white → `--hi`; translucent black ≥ 30% or on a scrim/backdrop → `--scrim`; a faint dark wash → `--line`; alpha 0 → `transparent` | as named |
| yumi | Yumi's seed, dot, send, caret, halo, dock — nothing else. Her dot's whole gradient is hers | `--yumi` (`color-mix` keeps a wash's alpha) |
| danger (ruling C) | red/coral or a destructive selector | text → `--gold-ink`, line → `--line`, fill → `--page-3` ? |
| fallback | the literal is only a `var()` fallback | dropped |
| UNTOUCHED | theory surfaces and the camera surface (below) | the literal stays |

Every row the method does not settle is **bold with `?`** and carries its best guess in "proposed token".
