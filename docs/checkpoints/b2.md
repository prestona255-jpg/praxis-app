## Reviewer finding — FIXED post-review

`fmt()` (generator) and `inline()` (client) applied bold/em AFTER code-spans with no masking,
so `` `*Loaded` `` + `` `*WritePending` `` in the account-switch item produced crossed tag-soup.
Fix: forbid `<` inside the bold/em captures (`[^*<]+`) so they cannot span an inserted `<code>`
tag; legit bold/em is unaffected (its text is `&lt;`-escaped, never a literal `<`). Verified in
the built HTML: malformed `<code><em>Loaded` = 0; clean `<code>*Loaded</code>` = 1; tags balanced;
runtime re-parsed PARSE OK.
