# The Lab

Ideas that are not yet a round — sparks, half-shapes, and named-but-unscheduled work.
The studio loop maps what's MISSING as rounds; **the Lab holds what's still just an
idea.** An idea graduates out of the Lab the moment it earns a `sequence.md` slot.
This file is the source of truth; the Builder's Lab page is a generated view.

`stage` reads left-to-right toward reality: **spark** (a raw notion, no shape) ->
**shaping** (a receiving surface or pattern exists; the shape is emerging) ->
**scheduled** (a real slot on the program tail, waiting its turn).
