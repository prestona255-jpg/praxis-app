# THE FELT SCRIPT — the human gate, scripted
v1 · July 19, 2026 · Runs after EVERY live ship, before any "pass." Five minutes, same every time — scripted so it catches categories, not coincidences.

## Setup (30 seconds)
1. Live site, hard refresh (Ctrl+Shift+R). Confirm the new version took (no stale SW).
2. Signed in as prestonpraxistest.

## The walk (same route, every ship)
1. **HOME** — sit back to arm's length at 1920. One world? Anything floating in void? Anything shouting?
2. **NOTEBOOK** — capture one real note (type it, commit it). Did the save answer your hand? Double-tap Capture fast — exactly one entry?
3. **AN ARC** — open the Field. Move one mark. Does it feel like touching a real thing?
4. **A BOOK** — open any Book Detail. Do the controls read as one dialect?

## The three questions (answer out loud)
- Does it feel like ONE world?
- Did anything SHOUT that should whisper — or whisper that should be readable?
- Did the app ANSWER my hand everywhere I touched it?

## The three contexts (rotate at least two per ship)
- The 1920 monitor (always)
- The phone, in the browser
- The INSTALLED PWA window (holds stale versions longest — worth one launch per ship)

## The verdict
- PASS = say "pass" and name anything small for the residual list.
- FAIL = name what felt wrong in PLAIN WORDS — no diagnosis needed. The feeling is the finding; the session finds the mechanism.

## The fifteen minutes that outrank all of it
After the pass, do fifteen minutes of REAL work in the app — not testing, thinking.
The instrument only proves itself being played.
